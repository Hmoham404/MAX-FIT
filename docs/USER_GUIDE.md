# Guide utilisateur (BackOffice)

1. **Connexion** : `/admin` → saisir votre code d’accès personnel.
2. **Ouvrir la caisse** (Caisse → Ouvrir) avant tout encaissement en espèces.
3. **Inscrire un client** : Clients → Inscrire. Pour un mineur, les champs parent/tuteur deviennent obligatoires. La catégorie est déduite de l’âge.
4. **Abonnement** : depuis la fiche client → Abonnement, choisir la formule, promotion, paiement immédiat éventuel → le reçu s’imprime.
5. **Encaisser un reste** : Abonnements → ouvrir → Encaisser.
6. **Entrée d’un client** : fiche client → Entrée (alerte si abonnement non valide).
7. **Planning** : glisser-déposer pour déplacer, double-clic pour créer, conflits coach/salle détectés.
8. **Pointage** : saisie ou auto-pointage du personnel (Mon espace), puis validation.
9. **Paie** : Salaires → mois → Préparer → primes/retenues → Valider → Bulletins PDF → Payer → Clôturer.
10. **Clôture de caisse** en fin de journée : saisir le solde compté, l’écart est calculé et notifié.
11. **Site web** : Site web (CMS) → modifier → Prévisualiser → Publier.
12. **Relances WhatsApp** : Notifications → Relances WhatsApp (envoi manuel).
